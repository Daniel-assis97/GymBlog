# 🏋️‍♂️ GymBlog

O **GymBlog** é um site institucional responsivo em formato de blog focado no mundo fitness, nutrição e ganho de massa muscular. O projeto foi desenvolvido aplicando conceitos modernos de HTML5 semântico, estilização avançada com CSS (Flexbox) e animações fluidas baseadas na rolagem da página através de JavaScript nativo.

---

## 🚀 Funcionalidades

- **Design Totalmente Responsivo:** O layout adapta-se perfeitamente a computadores, tablets e smartphones.
- **Animações de Entrada (Scroll Animation):** Elementos de conteúdo surgem de forma fluida à medida que o utilizador navega pela página, utilizando a eficiente API `IntersectionObserver`.
- **Formulário de Newsletter:** Captura de leads otimizada e estruturada semanticamente.
- **Menu Elástico:** Cabeçalho com distribuição elástica de elementos, garantindo integridade visual em monitores ultra-wide.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web nativas para garantir o máximo de performance e compatibilidade:

- **HTML5:** Estruturação semântica e acessível (`<header>`, `<main>`, `<section>`, `<article>`, `<form>`, etc.).
- **CSS3:** Estilização com propriedades flexíveis (Flexbox), layouts responsivos com Media Queries, gradientes lineares e otimização de renderização com `will-change`.
- **JavaScript (ES6):** Manipulação de DOM e controlo de animações performáticas através do `IntersectionObserver`.
- **Google Fonts:** Integração da fonte *Nunito*.
